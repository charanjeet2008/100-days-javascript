# 100-days-javascript
## 1st Day (Fri, 7th Dec 2018) 
Implemented LRU Cache. Controlled the limit of the cache using a finite Queue. and stored the key value pairs in a Hash.
Hash is modelled in traditional manner ie Array of Linked Lists. I used Object to model Linked List because of Javascript constraints. 

Hash can also be modeled as an Object containing literal values.
